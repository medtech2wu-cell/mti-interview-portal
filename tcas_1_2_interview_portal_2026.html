Supabase RLS Protected

ระบบจัดการข้อมูล Supabase Database

เข้าสู่ระบบโดยผู้ดูแล:

ข้อมูลนโยบายความปลอดภัย RLS บน Supabase Server

ฐานข้อมูลและนโยบายความปลอดภัย Row Level Security (RLS) บน Supabase Server ได้ถูกติดตั้งและตั้งค่าสิทธิ์ไว้อย่างถูกต้องแล้ว การเข้าถึงและแก้ไขข้อมูลผู้สมัคร สิทธิ์จะถูกบังคับผ่าน RLS กับบัญชีผู้ใช้ในตาราง admin_profiles โดยไม่เปิดสิทธิ์สาธารณะ

นำเข้าข้อมูลผู้สมัครจาก Excel / CSV

เลือกไฟล์ CSV เพื่ออัปโหลดข้อมูลเข้า Supabase Database (พร้อมระบบตรวจสอบความถูกต้อง)

รายชื่อผู้สมัครสอบสัมภาษณ์ (Supabase Synced)
